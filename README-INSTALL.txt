STORE UI v3

1. In the terminal, inside the frontend folder, run:
   rm -rf .next src/components "src/app/(store)" "src/app/(customer)" "src/app/(auth)" src/app/admin
2. Unzip this file and copy its "src" folder into frontend (say YES to replace files).
3. Start the site:  npm run dev   then open http://localhost:3000

Store name, UPI ID, WhatsApp number, delivery fee: src/lib/config.ts
Colours: top of src/app/globals.css
